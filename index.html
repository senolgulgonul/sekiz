Sekiz v1.0.3 · C/C++ compiler, assembler & cycle-accurate ATmega328P simulator

    
Sekiz is Turkish for eight — a single-file 8-bit AVR tool for teaching.
       Everything — C/C++ compiler (clang + lld built to WebAssembly), assembler, disassembler, CPU and peripherals — runs in this page. No server, no account.
       Assembly mode works offline instantly; Arduino .ino mode downloads the ~28 MB toolchain once (72 MB unpacked), then it is cached.

    
Quick start

    
Write AVR assembly in panel 1 (or pick an example), press Assemble, then Run.
       Step executes one instruction and follows the program counter in the machine-code listing.
       Click any listing row to toggle a breakpoint (red address); Run stops when the PC reaches it.
       Type in the box under the serial monitor and press Enter to send bytes to USART0 (RX).
       The red button on the board resets the running program.

    
Arduino .ino mode (in-browser compiler)

    
Switch the Program panel to Arduino .ino and press Compile. The first use downloads
       the toolchain (~28 MB download, 72 MB unpacked: real clang + lld built to WebAssembly, AVR backend) which your browser caches;
       after that, sketches compile locally in seconds. No server is involved at any point.
       Alternatively: compile in the Arduino IDE, Sketch → Export Compiled Binary, and use Load .hex.

    
Differences from avr-gcc (clang backend)

    
Delays: _delay_ms()/_delay_us() work, but run ~0.3% long: clang lacks
       __builtin_avr_delay_cycles, so Sekiz compiles with avr-libc's classic loop-based delay path.
       For cycle-exact timing use _delay_loop_2() or hand-written asm.
       Branch range: clang does not relax out-of-range rjmp/rcall (±4 KB). Very large loop
       bodies or big inline-asm blocks fail with “out of range branch target” — move the block into a
       noinline function. Plain avr-gcc accepts the same code silently.

    
Conventions

    
GAS-flavored syntax: labels are byte addresses (avr-gcc convention), lo8()/hi8(),
       numbers as 123, 0x7B, 0b1111011, 'A'. Complete ATmega328P instruction set.
       Assembler output validated instruction-by-instruction against avr-gcc; disassembler against avr-objdump.
